# NOXGPT

NOXGPT là giao diện AI hiện đại được xây dựng bằng HTML, CSS và JavaScript.

## Tính năng

- Giao diện tối giản
- LED đỏ nhẹ
- Responsive
- Sidebar
- API Key
- Markdown
- Highlight Code
- Copy Code
- Typing Effect
- New Chat
- Auto Scroll
