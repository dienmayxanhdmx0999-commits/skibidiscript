##  Tính năng

-  Chat AI thông minh
-  Hiệu ứng AI đang suy nghĩ
-  Giao diện LED đỏ/cam
-  Dark Mode
-  Tối ưu điện thoại
-  Hiệu ứng gõ chữ
-  Hỗ trợ Avatar
-  Markdown
-  Copy Code
-  Lưu lịch sử chat
-  Responsive
